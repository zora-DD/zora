## 文档维护原则

1. README 只描述使用者需要知道的能力、配置和运行方式。
2. 项目分析文档解释“为什么做、解决什么问题、有哪些取舍”。
3. 项目技术文档解释“代码如何工作、接口如何使用、如何扩展”。
4. 未完成能力必须标记目标版本，不能与已实现能力混写。
5. 代码修改涉及接口、事件、数据表或配置时，同一个变更中更新对应文档。
